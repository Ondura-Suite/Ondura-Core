# Privacy policy – Ondura

*As of 22 November 2026 · [Deutsche Fassung](privacy.de.md)*

Ondura is a desktop application that runs on your computer. The developer
does not operate any server for Ondura and does not receive, collect or
store any personal data about you or the content you work with.

## What stays on your computer

- Mail, calendar, contact and task data that Ondura keeps for offline use, your settings,
  notebooks, plans and recently used files are stored only on your computer.
- Passwords and sign-in tokens are stored in the Windows Credential Manager
  (on Linux: Secret Service, on macOS: Keychain).
- Documents you open or save stay where you keep them.
- Uninstalling Ondura from the Microsoft Store removes the data the Store version stored.

Ondura contains no telemetry, no analytics, no advertising and no crash reporting.

## Connections Ondura makes

Ondura connects directly to the services you set up or use. The developer is not
involved in these connections, and the privacy policies of those services apply.

| Service | When | What is sent |
| --- | --- | --- |
| Your mail, calendar and contact servers (IMAP/SMTP, Exchange, CalDAV/CardDAV) | While Ondura Mail runs | Your sign-in and the data you send or sync |
| Microsoft 365 / Microsoft account (`login.microsoftonline.com`, `graph.microsoft.com`, OneDrive, SharePoint) | When you add such an account or open files from OneDrive/SharePoint | Sign-in through Microsoft, then your mail, calendar, contacts, tasks, notebooks, plans and files as you use them |
| Automatic account setup (`autoconfig.thunderbird.net`, `cloudflare-dns.com`, `autoconfig.<domain>`, `autodiscover.<domain>`, `/.well-known/ondura-server` on `<domain>` and `mail.<domain>`) | When you add an account | Only the domain of your e-mail address |
| Weather in the calendar (Open-Meteo) | Only when you switch it on | The place name you enter |
| Grammar check (LanguageTool) | Only when you start it in Ondura Text | The text being checked, to the server set in the dialog |
| Translation (LibreTranslate or DeepL) | Only when you start it in Ondura Text | The text being translated and, for DeepL, your own API key |
| Web data in Ondura Sheets | Only when you add such a query | A request to the address you enter |
| Updates (GitHub) | Versions installed from the website only; the Microsoft Store version is updated by the Store | A check for new versions; GitHub sees your IP address |

## Microsoft Store

When you install Ondura from the Microsoft Store, Microsoft processes data for
the download, licensing and updates under the
[Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement).
The developer receives only the aggregated, anonymous statistics that Microsoft
provides to all app publishers (such as numbers of installs).

## Children

Ondura is not directed at children and collects no data about them.

## Your rights

Because the developer holds no personal data about you, there is nothing to access,
correct or delete on our side. Your data in Ondura is under your control on your
computer and at your mail or cloud provider. For questions, write to the address above.
You also have the right to lodge a complaint with a data protection supervisory authority.

## Changes

If this policy changes, the new version is published here with a new date.
